# shape.js

## Описание

Фигуры по путям из Figma: углы сохраняют размер, прямые участки тянутся. В элемент первым ребёнком кладётся
`<svg class="shape-layer"><path/></svg>`: это фон и обводка. Сам элемент клипается тем же путём
(`clip-path: path()`). Форма пересчитывается, когда меняется размер элемента, брейкпоинт или атрибуты.

Каждая точка пути привязывается к ближнему краю. `x` левее середины фрейма считается от левого края,
правее середины - от правого; так же по `y`. Поэтому вырезы сохраняют размер, а прямые участки
тянутся под реальный размер элемента.

Цвета задаёт CSS. Готовые правила есть в st-style, атрибут `shape`: `--shape-bg`, `--shape-line`, `--shape-width`.
Умолчания там не объявлены на элементе, поэтому ховер родителя перекрашивает фигуру на дочернем `__bg`.

Подключение:

```js
// ESM / npm
import Shape from '@cat-of-summer/st-script/shape';
```

```html
<!-- CDN / IIFE: объявляет глобальный Shape -->
<script defer src="dist/shape.min.js"></script>
```

## Разметка

```html
<div shape="594 237 | M10.4 1L1 10.2V134.4L10.4 144H594V1Z" shape-lp="1200 300 | M…Z">…</div>
```

| Атрибут | Значение |
|---|---|
| `shape` | `ширина высота \| d`: размер фрейма в px макета и путь Figma как есть (абсолютные `M L H V C S Q Z`). Кривые (скругления в пару px) заменяются отрезком до конечной точки |
| `shape-<брейкпоинт>` | своя фигура от `min` этого брейкпоинта и шире (`shape-md`, `shape-lp`…). Берётся самый широкий подходящий брейкпоинт с заданной фигурой |

Путь копируется из Figma: Copy as SVG, атрибут `d` у `<path>` фигуры. Размер берётся из `width` и `height` того же svg.

## Статические методы

| Метод | Описание |
|---|---|
| `Shape.find(element \| selector)` | экземпляр, которому принадлежит элемент (или `undefined`) |

## Конструктор

```js
new Shape(params)
```

### Основные параметры

| Параметр | По умолчанию | Описание |
|---|---|---|
| `target` | `'[shape]'` | элементы: селектор, Element, NodeList, массив |
| `attribute` | `'shape'` | имя атрибута; варианты - `<attribute>-<брейкпоинт>` |
| `breakpoints` | `{ xs: 360, sm: 576, md: 768, lp: 1024, lg: 1280, dt: 1536, xl: 1920 }` | шкала брейкпоинтов (min, px). По умолчанию это шкала st-style. Своя шкала проекта передаётся сюда же |
| `scale` | `10` | px макета в `1rem`: координаты переводятся в rem и масштабируются вместе с вёрсткой. `0` - без масштаба, 1px макета = 1px экрана |

### callbacks

| Хук | Аргументы | Когда |
|---|---|---|
| `before_init` | `params` | до привязки элементов |
| `on_init` | `params` | после привязки |
| `on_draw` | `element, d` | после каждого пересчёта формы |

## Методы

- `refresh(target = params.target)` - перечитать атрибуты и перерисовать. Элементы под `target`, которых
  ещё нет у экземпляра, берутся под управление: так подключают разметку, добавленную после инициализации.
- `destroy()` - снять наблюдатели и слушатели, убрать svg, вернуть элементу прежний `clip-path`.
- `clone(params)` - новый экземпляр с теми же параметрами и хуками.

## Свойства

- `params` - параметры экземпляра.
- `elements` - элементы под управлением.

## Замечания

- Клип срезает всё, что выходит за фигуру. Выступающие картинки и тени - повод поставить фигуру на
  дочерний слой (`__bg` с `position: absolute; inset: 0; z-index: -1`), а не на саму карточку.
- Обводка рисуется по краю клипа, видна её внутренняя половина: `stroke-width: 2px` даёт линию в 1px.
- Атрибут меняется из кода (`el.setAttribute('shape-lp', …)`) - форма перечитывается сама.

## Пример

```js
// Шкала брейкпоинтов проекта и макет с 1rem = 10px
new Shape({
    breakpoints: { md: 768, lp: 1024 },
    scale: 10,
    on_draw(el, d) { el.dataset.shapeReady = ''; },
});
```
