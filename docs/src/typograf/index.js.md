# Typograf.js

## Описание

Расставляет неразрывные пробелы в русском тексте: предлоги и союзы не висят в конце строки,
частицы не отрываются от своих слов, числа — от единиц, инициалы — от фамилий, а последнее
слово абзаца не остаётся на строке одно. Пишет прямо в `nodeValue` текстовых узлов: тегов не
добавляет, структуру DOM не меняет.

Один инстанс обслуживает все подходящие цели. Цели у экрана обрабатываются сразу, дальние —
при приближении. Правки текста (фреймворки, сторонние скрипты, `innerHTML`) подхватываются
`MutationObserver`: новый текст остаётся новым и сразу получает склейки.

Склейки не зависят от ширины: NBSP запрещает разрыв в конкретном месте, а где пройдёт перенос,
решает браузер. Поэтому ресайз ничего не пересчитывает.

## Правила

| Правило | Что клеит | Пример |
|---|---|---|
| `words` | Предлог, союз, частицу — к следующему слову | `жил в~доме`, `а~и~в~саду`, `«в~доме»` |
| `particles` | `же`, `ли`, `бы`, `б`, `ж`, `ль` — к предыдущему слову | `он~же`, `был~бы рад` |
| `numbers` | Число — к следующему слову | `2024~год`, `10~000~рублей` |
| `dash` | Слово — к тире после него | `Москва~— столица` |
| `abbr` | Сокращение — к следующему слову | `т.~е.`, `и~т.~д.`, `г.~Москва`, `№~5` |
| `initials` | Инициалы — к фамилии | `А.~С.~Пушкин`, `Пушкин~А.~С.` |
| `last_word` | Последнее слово строки — к предпоследнему | `Он сказал~правду.` |
| `max_chain` | Не правило, а предел: цепочка не длиннее 14 символов, лишняя связь — самая дальняя — отпускается | `А когда~наступал`, `как над~городом` |

`~` — неразрывный пробел. Словари и точные условия — в [_engine.js](_engine.js.md).

**Сквозь inline-теги.** Текст абзаца склеивается в одну строку через элементы с вычисленным
`display: inline` или `contents` (`<b>`, `<a>`, `<span>`, `<em>`…): `в <b>доме</b>`,
`<a>на</a> сайте` клеятся так же, как обычный текст. Слово, разрезанное тегом (`сло<b>во</b>`),
со словарным «во» не путается.

**Где кончается строка.** Прогон текста прерывают блочные элементы, `inline-block`, замещаемые
элементы и пропускаемые. `last_word` срабатывает в конце блока и перед `<br>`; там, где строку
прерывает `<code>` или `inline-block`, — нет.

## Что не трогается

- Элементы под `skip` (по умолчанию `script`, `style`, `noscript`, `template`, `code`, `pre`,
  `textarea`, `kbd`, `samp`, `var`, `svg`, `math`, редактируемые `[contenteditable]` и
  `[typograf-skip]`). Правки внутри них не вызывают обработку — ввод в редактор не правится
  под курсором.
- Блоки с вычисленным `white-space: pre`, `pre-wrap`, `pre-line`, `break-spaces`: там перевод
  строки значимый, и замена пробела на NBSP сломала бы вёрстку.
- Промежутки, уже целиком неразрывные: авторские `&nbsp;`, узкий пробел `&#8239;`.

## Конструктор

```js
new Typograf(params)
```

| Параметр | По умолчанию | Описание |
|---|---|---|
| `target` | `'[typograf]'` | Селектор / Element / NodeList целей |
| `root` | `null` | Контейнер прокрутки для ленивости (селектор / Element); `null` — viewport |
| `lazy` | `true` | Обрабатывать цель, когда до неё остаётся не больше экрана. `false` — все цели сразу |
| `live` | `false` | Подхватывать новые цели по `target` (`MutationObserver` на документе). Только для строкового `target` |
| `rules` | `{}` | Поверх правил по умолчанию: `{ last_word: false }` выключает одно правило, `{ max_chain: 20 }` меняет предел цепочки, `{ max_chain: 0 }` снимает его |
| `skip` | см. выше | Селектор того, что не трогается. Свой список заменяет стандартный целиком |

### Хуки

Передаются в `params` и привязываются к инстансу (`this` — Typograf). Ошибка в хуке пишется в
консоль и не мешает обработке.

| Хук | Аргументы | Когда |
|---|---|---|
| `before_init` / `on_init` | `(params)` | В начале и в конце конструктора |
| `on_apply` | `(el)` | Цель обработана: первый раз или после правки её текста |

## Публичные методы и свойства

| Член | Описание |
|---|---|
| `observe(target)` | Взять цели в работу, в том числе отпущенные раньше через `unobserve`; возвращает `this` |
| `unobserve(target)` | Отпустить цели и вернуть их исходный текст; при `live` по селектору заново не берутся |
| `apply(target?)` | Обработать сейчас, мимо ленивости; без аргумента — все цели |
| `refresh()` | Пересканировать `target`, отпустить ушедшие из DOM, пересчитать цели у экрана |
| `destroy()` | Отключить наблюдателей и вернуть исходный текст всем целям |
| `clone(params)` | Новый инстанс с объединёнными параметрами (`rules` мержатся) и `parent: this` |
| `params` | Конфигурация без функций |
| `elements` | Цели в работе |
| `Typograf.find(el)` | Инстанс, владеющий целью |
| `Typograf.text(str, rules?)` | Типографика строки без DOM: для шаблонов, `title`, `alt` |

## Как устроено внутри

- **Движок** — чистые функции [_engine.js](_engine.js.md): `glue(parts)` получает тексты
  текстовых узлов одного прогона и возвращает их со склейками, сохраняя число частей.
- **Обход** — цель обходится по дереву; текстовые узлы собираются в прогоны до первой
  границы (блок, `<br>`, `inline-block`, пропускаемый элемент). Каждый прогон проходит через
  движок; узел перезаписывается, только если его текст изменился.
- **Исходный текст** — на уровне модуля два `WeakMap`: `originals` (текст до первой правки) и
  `written` (что записано последним). Обработка всегда идёт от исходного текста, поэтому при
  дописывании абзаца склейка прежнего последнего слова снимается. Если `nodeValue` отличается
  от `written`, текст изменил кто-то другой — новое значение становится исходным.
- **Свои записи** — отличаются от чужих сравнением с `written`, без `takeRecords()`: чужие
  правки, пришедшие в том же такте, не теряются.
- **Правки** — `MutationObserver` по каждой цели (при `live` — один на документ). Правка
  пересчитывает только блок, в котором произошла: подъём от узла по inline-предкам.
- **Ленивость** — `IntersectionObserver` с `rootMargin: 100%`. Цели у экрана обрабатываются
  синхронно в конструкторе, без мигания сырого текста. Правка в далёкой цели помечает её
  грязной и применяется при подходе.

## Примеры

### Весь контент статьи

```html
<article typograf>…</article>
<script defer src="dist/typograf.min.js"></script>
<script>addEventListener('DOMContentLoaded', () => new Typograf())</script>
```

### Контент, который рендерит фреймворк

```js
new Typograf({ target: '[typograf]', live: true });   // новые [typograf] подхватываются сами
```

Правки текста внутри целей подхватываются и без `live`; он нужен, только когда в DOM
появляются новые цели.

### Только заголовки и лид, без последнего слова

```js
new Typograf({ target: 'h1, h2, .lead', rules: { last_word: false } });
```

### Строка без DOM

```js
el.title = Typograf.text('Скидка 10 % на все товары в магазине');
```

### Отключить на фрагменте

```html
<p typograf>Обычный текст. <span typograf-skip>Здесь — как написано.</span></p>
```

Демо со всеми правилами, живыми правками и ленивым блоком — `examples/typograf.html`.

## Ограничения

- **Inline определяется по вычисленному `display`.** `<span style="display:block">` —
  граница прогона, `<div style="display:inline">` — нет. Так склейки следуют вёрстке, но
  обход цели вызывает `getComputedStyle` для каждого элемента.
- **Узкие колонки.** Цепочка склеенных слов переносится только целиком. Предел `max_chain: 14`
  держит цепочки в ~120–130 px при шрифте 16 px; в колонке уже этого цепочка вылезет, как
  вылезло бы и одно длинное слово. Для крупного шрифта или узких карточек уменьшите
  `max_chain`, для широкой колонки его можно поднять.
- **Текст, переписанный чужим кодом из обработанного,** несёт уже поставленные NBSP:
  `el.textContent = el.textContent + '…'` сохранит прежние склейки, и после `destroy()` они
  останутся.
- **Ленивость считает от viewport.** При `lazy: true` цели дальше экрана от видимой области не
  обработаны, пока до них не дошла прокрутка: копирование текста страницы или поиск по ней
  увидят их без склеек. Для таких случаев — `lazy: false` или `apply()`.
- **Одна цель — один Typograf.** Цель, уже занятая другим инстансом, пропускается с
  предупреждением.
